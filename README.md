# Mayın Tarlası Oyunu

Bu proje C++ ve SFML kullanılarak geliştirilmiş bir Mayın Tarlası oyunudur.  
Oyunda farklı zorluk seviyeleri, mayın yerleştirme, hücre açma, bayrak koyma ve oyun sonu ekranları bulunmaktadır.

## Kullanılan Teknolojiler

- C++
- SFML Graphics
- SFML Audio
- Visual Studio / VS Code

## Oyun Özellikleri

- Kolay, orta ve zor zorluk seviyeleri
- Rastgele mayın yerleştirme
- Hücreye tıklayınca çevredeki mayın sayısını gösterme
- Boş hücrelerde otomatik alan açma
- Bayrak koyma sistemi
- Kazanma ve kaybetme ekranları
- Ses efektleri ve müzik desteği

## Kontroller

| Tuş / İşlem | Görev |
|---|---|
| Sol tık | Hücre açar |
| Sağ tık | Bayrak koyar |
| Enter | Oyunu başlatır / tekrar oynar |
| Esc | Çıkış yapar |
| Tab | Nasıl oynanır ekranı |

## Zorluk Seviyeleri

| Seviye | Boyut | Mayın Sayısı |
|---|---|---|
| Kolay | 12 x 11 | 10 |
| Orta | 27 x 13 | 30 |
| Zor | 40 x 20 | 40 |
